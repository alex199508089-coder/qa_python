1. test_add_new_book
Параметризованный тест метода add_new_book. Проверяет добавление книг с допустимыми и недопустимыми названиями:

Книга с именем из одного символа ("A") добавляется, жанр — пустая строка.

Книга с кириллическим названием ("Война и мир") добавляется.

Максимально допустимая длина (ровно 40 символов) — добавляется.

Пустая строка ("") — не добавляется.

Слишком длинное название (41 символ) — не добавляется.

2. test_add_new_book_duplicate_preserves_genre
Проверяет, что повторное добавление уже существующей книги не перезаписывает установленный ранее жанр. 
После добавления книги и присвоения ей жанра "Мультфильмы" повторный вызов add_new_book не меняет жанр, 
и get_book_genre возвращает прежнее значение.

3. test_set_book_genre
Параметризованный тест метода set_book_genre:

Книга существует, жанр входит в список допустимых — жанр успешно устанавливается ("Фантастика").

Книга существует, но жанр недопустим ("Роман") — жанр остаётся пустой строкой.

Книга отсутствует в словаре — попытка установить жанр игнорируется, get_book_genre возвращает None.

4. test_get_book_genre
Параметризованный тест метода get_book_genre:

Для книги, которой ранее задали жанр, возвращается корректный жанр ("Фантастика").

Для книги, добавленной без указания жанра, возвращается пустая строка.

Для несуществующей книги возвращается None.

5. test_get_books_with_specific_genre
Параметризованный тест метода get_books_with_specific_genre:

Запрашиваем жанр "Фантастика", ожидаем список с книгой "Пикник на обочине".

Запрашиваем допустимый жанр "Детективы", для которого нет книг — пустой список.

Запрашиваем жанр "Роман", отсутствующий в списке допустимых — пустой список.

Запрашиваем допустимый жанр "Мультфильмы", но книг с ним нет — пустой список.

6. test_get_books_genre
Проверяет, что метод get_books_genre возвращает актуальный словарь книг и их жанров после добавления двух книг 
— одной с установленным жанром и одной без.

7. test_get_books_for_children
Параметризованный тест, покрывающий разные комбинации книг:

Часть книг с «детскими» жанрами, часть — с возрастным рейтингом, одна без жанра: 
возвращается только книга с допустимым жанром.

Все книги имеют возрастной рейтинг — пустой список.

Все книги имеют жанры без возрастного рейтинга — возвращаются обе.

8. test_add_book_in_favorites
Параметризованный тест, объединяющий добавление в избранное и защиту от дублирования:

Книга существует в словаре — добавляется в избранное, длина списка становится 1.

Книга отсутствует в словаре — не добавляется, длина 0.

Двукратный вызов для одной и той же книги — длина списка остаётся 1 (дубликат не появляется).

9. test_delete_book_from_favorites
Параметризованный тест метода delete_book_from_favorites:

Удаляем книгу, которая есть в избранном — она исчезает.

Пытаемся удалить книгу, которой в избранном нет — ничего не происходит, список остаётся пустым.

10. test_get_list_of_favorites_books
Проверяет, что get_list_of_favorites_books возвращает корректный список избранных книг. 
Добавлены две книги, в избранное помещена только одна, метод возвращает список с единственной книгой.
